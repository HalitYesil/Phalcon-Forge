# PhalconDocs Kaynak Politikasi

Bu projede dokuman uretimi icin sadece asagidaki URL'ler kaynak kabul edilir:

- `https://docs.phalcon.io/5.11/introduction/`
- `https://docs.phalcon.io/5.9/introduction/`

Ana kaynak repository:

- `https://github.com/phalcon/documentation.git`
- aktif branchler: `5.9.x`, `5.11.x`
- planlanan branch: `6.0.x` (release sonrasi eklenecek)

## Kurallar

- Surumler birbirine karistirilmaz.
- Gecmis/hallusinatif veri kullanilmaz.
- Ozetleme yapilacaksa dogrudan URL iceriginden yapilir.
- Branch bazli cekimlerde sadece ilgili surum branch'i kullanilir.
- Snapshot dosyalari:
  - `phalcondocs/sources/5.11/introduction.md`
  - `phalcondocs/sources/5.9/introduction.md`
