# Phalcon Team Skill

Bu skill, Phalcon gelistirmede ekip standardizasyonu ve yeniden kod yazimini azaltma amaciyla kullanilir.

## Akis

1. Use-case'i analiz et.
2. `skill/phalcon-map/` icinden kategori bazli mevcut capability ara.
3. Gerekirse `phalcondocs/index/` ve MCP tools ile detay cek.
4. Yerlesik Phalcon cozumunu tercih et; custom kodu son secenek yap.
5. Guvenlik ve test checklist adimlarini uygula.

## Zorunlu Kontroller

- Input sanitize/validate
- Output escape
- Security headers (CSP, X-Frame-Options, HSTS)
- Prepared statements
